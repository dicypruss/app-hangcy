# Hangcy Privacy Policy

Last updated: 29 August 2026

Hangcy is a caller ID and call screening app. You choose which inserted SIM should reject incoming calls. If the device does not list SIMs, one toggle covers all incoming calls. Calls on a line with the toggle off are not changed by Hangcy.

## Permissions

Hangcy asks for:

- **Contacts.** Android only sends calls from your contacts to a call screening app if this permission is granted. Hangcy uses it so rejected lines also drop calls from people in your address book. It does not upload your contacts.
- **Phone.** Used to tell which SIM received an incoming call, so each line can have its own toggle.
- **Notifications.** Used to show a local “Call rejected” notice on this device.

Hangcy must be set as the Caller ID app on the device for screening to run.

## Data stored on this device

When Hangcy rejects a call, it stores the caller number and the time in a file on this device (at most 100 entries). That list is shown in the app. Uninstalling Hangcy removes it.

Hangcy has no accounts, no ads, and no Hangcy servers. It does not send your contacts, call numbers, or SIM details to us.

## Backup

Hangcy is excluded from Android backup so rejected-call numbers are not copied into a cloud backup of this device.

## Changes

If this policy changes, the updated text ships in the app.
